# Programming-curiositys

Programming Curiosity 🚀

This repository is not about memorizing programming answers. It is about
understanding why, what, how, where, when, who, and what if behind the
technology we use every day. Every question is an opportunity to go one level
deeper. Don’t just learn code. Understand what happens behind the code.

## Programming Curiosity Challenge

The challenge is to ask: **“But how does this actually work?”**

Don’t search for the answers immediately. First pick questions, discuss them
with your team, and make your own assumptions; then compare them with the
explanations in the chapters. The 100 challenge questions are grouped with
their answers in the matching topic files. Answers use the seven-question
framework as a guide without repeating all seven headings for every question.

## Keep Asking

Whenever you learn something, ask seven questions:

**WHY? → WHAT? → HOW? → WHERE? → WHEN? → WHO? → WHAT IF?**

For example, don’t stop at “I learned MongoDB.” Ask:

- **WHAT** is MongoDB?
- **WHY** do we use it?
- **HOW** does it store data?
- **WHERE** is the data physically stored?
- **WHEN** should I choose MongoDB?
- **WHO** uses it in the industry?
- **WHAT IF** MongoDB goes down?

A good programmer doesn’t just learn answers. A good programmer develops
better questions.
