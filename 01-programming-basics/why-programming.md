# Why Programming?

Programming is a way to describe steps that a computer can follow to solve a problem or create something useful.

## What you'll learn

- How programs turn ideas into repeatable instructions
- Where software shows up in everyday life
- Why breaking a problem into smaller steps helps

## Curiosity Questions

1. What exactly is programming?

   Programming is designing and writing precise instructions that a computer
   can execute to process information or perform a task. It includes more than
   code: understanding the problem, choosing a solution, testing it, and
   maintaining it are all part of programming.

2. Why was programming invented?

   People needed reliable ways to make machines perform calculations and
   repetitive tasks faster and more consistently than doing them by hand.
   Programming grew from those needs into a way to automate work, model ideas,
   communicate, and build tools that would be impractical to operate manually.
