# NoSQL Databases

NoSQL is a broad term for database systems that use data models beyond the traditional relational table model.

## What you'll learn

- Common document, key-value, graph, and wide-column models
- How data shape influences database choice
- Why NoSQL does not mean there are no query languages

## Curiosity Questions

70. What is the difference between SQL and NoSQL?

   SQL commonly refers to relational databases, which organize data into
   tables and use SQL as a query language. NoSQL describes a range of
   non-relational models, including documents, key-value pairs, graphs, and
   wide columns. Both categories can support queries, indexes, transactions,
   and consistency features; choose based on data shape, access patterns,
   constraints, and operational needs rather than the label alone.
