# HTTPS

HTTPS is HTTP carried over a secure connection, commonly using TLS to protect communication.

## What you'll learn

- How encryption helps keep traffic private
- How certificates help authenticate a server
- What HTTPS does and does not guarantee

## Explore further

Review [HTTP](http.md) to understand the protocol HTTPS protects.

## Curiosity Questions

47. Why was HTTPS created?

   Plain HTTP does not protect traffic against someone on the network reading
   or modifying it. HTTPS uses TLS to encrypt the connection, detect
   tampering, and authenticate the server using certificates. It protects
   data in transit, but does not guarantee that a site is honest, secure, or
   safe after data reaches it.
