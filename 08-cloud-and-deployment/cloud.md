## Curiosity Questions

96. What is cloud computing?

   Cloud computing provides on-demand access over a network to resources such
   as virtual machines, storage, databases, and managed software. Customers
   can provision and release many resources without owning the underlying
   data-centre hardware, while still having responsibilities for their
   applications, configuration, and data.

97. What is AWS or Azure actually providing?

   Providers such as AWS and Azure offer infrastructure and managed services:
   compute, networks, storage, databases, identity tools, monitoring, and
   other capabilities. Their services run on provider-operated data-centre
   hardware. Customers configure and pay for the services they use and remain
   responsible for their portion of security and operations.
