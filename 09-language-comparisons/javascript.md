## Curiosity Questions

82. Why is JavaScript used in browsers?

   JavaScript is built into modern browsers and can interact with web-page
   elements, handle events, and make network requests. Browser engines
   implement the language and web APIs, allowing pages to run interactive
   code without a separate language runtime being installed by the user.

83. Why is Node.js able to run JavaScript on servers?

   Node.js embeds the V8 JavaScript engine and provides server-side APIs for
   tasks such as files, networking, and processes. This lets JavaScript run
   outside a browser; Node.js is a runtime environment, not a different
   programming language.
