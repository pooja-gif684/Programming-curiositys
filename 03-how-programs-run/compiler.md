# Compiler

A compiler translates a program from one representation into another, often preparing it for execution.

## What you'll learn

- Why compilers analyze and transform source code
- The difference between compilation and execution
- How compiled output can depend on its target platform

## Explore further

Compare this with an [interpreter](interpreter.md), which commonly executes program instructions through a runtime.

## Curiosity Questions

9. Why does a programming language need a compiler or interpreter?

   Processors execute machine instructions, while programmers usually write
   in more expressive languages. A compiler or interpreter bridges that gap
   and can also check, optimize, or manage execution. Not every language uses
   a separate compiler or interpreter in the same way; many combine
   compilation and runtime interpretation.
