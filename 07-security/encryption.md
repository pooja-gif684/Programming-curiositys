# Encryption

Encryption transforms readable data into a protected form that can be recovered with the appropriate key.

## What you'll learn

- The difference between symmetric and public-key encryption
- How keys control access to encrypted data
- Why encryption does not replace authentication or authorization

## Curiosity Questions

74. What is encryption?

   Encryption uses an algorithm and a key to transform readable data into
   ciphertext that can be recovered by someone with the appropriate key.
   Symmetric encryption uses a shared secret key; public-key cryptography
   uses related public and private keys for tasks such as key exchange or
   digital signatures. Correct key management matters as much as the
   algorithm.
